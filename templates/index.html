Yeh downloader fully-featured REST API offer karta hai jise aap apne Python script, Node.js app, ya mobile app me use kar sakte hain:

GET /api?url=https://www.youtube.com/watch?v=...

Video metadata, title, duration aur sabhi qualities ke direct download links ka complete JSON response.

curl "http://localhost:5055/api?url=https://www.youtube.com/watch?v=7SlptRQ_kPU"
POST /api/info

Video metadata, title, duration aur available resolutions retrieve karne ke liye.

curl -X POST http://localhost:5055/api/info \ -H "Content-Type: application/json" \ -d '{"url": "https://www.youtube.com/watch?v=..."}'
POST /api/download

Background download shuru karne ke liye (Returns job_id).

curl -X POST http://localhost:5055/api/download \ -H "Content-Type: application/json" \ -d '{"url": "https://www.youtube.com/...", "type": "video", "quality": "1080p"}'
GET /api/progress/<job_id>

Download percentage, speed aur ETA check karne ke liye.

curl http://localhost:5055/api/progress/job_12345
GET /api/file/<filename>

In-browser video streaming (`<video src="...">`) ya direct file download (`?download=1`).
